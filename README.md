# hanser-mgclub-boss-reply-filter
使用此脚本，可以实现对毛怪俱乐部的所有帖子实现遍历以筛选出hanser回复过的帖子
# 🐾 毛怪俱乐部 - hanser 互动帖子提取器

自动检索并提取 [毛怪俱乐部 (2550505.com)](https://2550505.com) 中 hanser 互动过的帖子（包括主楼正文、hanser 楼层回复内容等），支持一键增量追新与离线归档。

---

## ✨ 核心特性

- 📦 **内置全量历史数据**：开箱即拥有全部历史互动帖数据，无需耗时全站重扫。
- ⚡ **智能增量同步**：自上次扫描时间点向后检索，遇到已收录时间点自动停止，日常追新仅需 1~3 秒。
- 📖 **全文字提取与归档**：
  - **完整 JSON 导出**：包含主楼正文文字、发布者信息、hanser 楼层回复内容等。
  - **精简 TXT 清单**：按序号、标题、ID、直达链接与时间排版，适合快速浏览。
- 🛡️ **安全平滑调度**：内置动态 Jitter 随机延时与缓冲保护，不对论坛服务器造成额外负载。
- ⚙️ **灵活高级设置**：支持折叠展开自定义按页码范围扫描与筛选模式。

---

## 🚀 安装与使用

### 1. 准备工作
- 安装现代浏览器扩展：[Tampermonkey (油猴)](https://www.tampermonkey.net/)。

### 2. 安装脚本
- 打开油猴扩展管理面板，新建用户脚本，将本仓库的 `hanser-extractor.user.js` 代码复制粘贴并保存。
- 或使用About贴出的greasyfork链接：[![GreasyFork](https://img.shields.io/badge/GreasyFork-前往安装脚本-red.svg)](https://greasyfork.org/zh-CN/scripts/593050)

### 3. 开始使用
1. 打开并登录 [毛怪俱乐部 (2550505.com)](https://2550505.com)；
2. 页面右下角将出现 **【🐾 hanser 帖子提取】** 悬浮按钮，点击展开控制面板；
3. 点击 **【⚡ 一键增量扫描】** 即可同步最新发布的互动帖子；
4. 扫描完成后，点击 **【💾 下载完整 JSON】** 或 **【📥 下载精简 TXT】** 即可离线保存。
